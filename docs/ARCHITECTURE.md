# 首版实现结构

## 进程和数据

主进程持有 Room、页面和前台服务。`RecordingService` 持有 AudioRecord，读取、音频保存和识别任务调度不依赖页面。`AsrService` 位于独立绑定进程 `:asr`，通过 Messenger 接收内部短段 WAV 路径、固定模型选择和请求编号，串行识别后回传文字。它不打开数据库，不持有麦克风。

数据库保存七类对象：课堂、音频分文件、转写短段、照片、云端整理任务、批次笔记、人工修改笔记（共七张业务表；批次的工具消息与回执保存在批次表）。所有课堂资料位于应用内部目录 `files/lessons/<lessonId>/`。

数据库版本 2 通过非破坏性迁移追加课堂的 `sourceType` 与 `importReady`。旧记录默认仍为麦克风录音；不删除旧表、录音或笔记。

## 录音与恢复

音频总样本数是唯一录音时钟。暂停不累加。照片按钮按下时读取样本数并记录独立的 Unix 拍摄日期。

课堂状态：`recording → paused → recording → processing → completed`。异常/冷启动恢复将未结束录音标为 `interrupted`。只有用户可见界面启动麦克风前台服务。持续通知支持暂停、继续、停止；服务不随任务页面关闭结束。

WAV 每 30 秒换文件，每秒修正头部、同步文件并更新样本数。冷启动按真实文件长度恢复头部及末段时长。识别短段在排队前落盘并建立 `pending` 记录；成功为 `ready`，失败为 `error`。继续录音或“完成待转写段落”只恢复未完成段落，不重新识别已完成段落或整节课。

分段采用音量门限、0.25 秒前置音频、0.6 秒停顿和约 15 秒上限。临时结果约两秒请求一次，过期临时任务会跳过；最终段落始终保留。识别进程断开或调用失败不会结束录音，最终任务至多尝试两次，仍失败则保留待恢复记录。

正在采集或处理任务时使用十分钟超时唤醒锁，五分钟按任务状态续租；暂停且队列排空后释放。厂商后台限制和 Doze 条件仍需真机验收。

## 照片

数据库事务预留递增序号，排他创建文件以避免重名；图片写入成功后才提交照片记录。名称包含音频相对毫秒与序号。照片的选择和人工文字编辑增加来源版本；编号和时间不变。

方向监听器持续更新 ImageCapture 的目标方向；拍摄时冻结本次方向。照片缩略图及云端编码根据原始 EXIF 旋转/镜像，原图不改写。拍照页面状态随 Activity 重建恢复；详情页区分尚未加载与实际不存在的记录，避免旋转时误回首页。

## 音频导入

系统文件选择器授权读取音频，复制到本机后由 MediaExtractor / MediaCodec 流式解码。PCM WAV 直接读取采样数据；压缩格式由平台解码。声道合并与带低通滤波的重采样统一为 16 kHz 单声道，按 30 秒写回听 WAV，识别短段沿用现有分段与 AsrClient。

`AudioImportService` 使用 dataSync 前台服务，不请求麦克风权限。转换结果在完整成功后通过数据库事务提交；取消或失败清理新生成的未提交音频，保留原文件。已成功转写的段落在重试时跳过。任务状态与运行时占用均参与删除保护。冷启动将未结束导入标为可继续。

导入课堂类型固定为 `import`，界面不提供追加麦克风录音或照片，录音服务和拍照提交也检查类型。笔记快照对导入记录强制排除照片，转写未结束时不允许整理。

## 云端任务

预设默认生成“预设一”“预设二”，支持新增及重命名。旧配置复制到首个预设，密钥继续由 Keystore 加密；每个预设有独立配置和测试状态。修改名称不使通过状态失效，修改请求配置或重新测试会失效。

OpenCode Go 使用 `/zen/go/v1` 路径，与 Zen 的配置分开。客户端发送真实 `RecNote/<version>` 身份和 `x-opencode-session`，笔记任务编号在批次及恢复时保持稳定。当前支持该服务的 Chat Completions 模型；不伪装为其他编程客户端。

设置提供 DeepSeek、OpenRouter、OpenCode Zen、OpenAI 和自定义配置。每个供应商有独立配置和 Keystore 加密密钥；切换页面中的草稿不改变正在使用的配置。保存时规范化 HTTPS 基础地址，接受完整 `/chat/completions` 地址并保留网关路径。修改任一请求配置会失效该配置的测试状态，旧版单配置按官方域名迁移，首次升级要求重测。

连接测试分为普通文字回复、文字笔记与本地保存回执、可选读图三步。后一项失败不会把前面的成功显示为地址错误；只有所有已启用步骤都通过才允许整理。HTTP 错误读取有界 JSON 错误信息，显示状态和经过密钥脱敏的供应商说明；不跟随跳转。模型列表是辅助选择，仍需完成能力测试。

DeepSeek 适配按实际官方域名识别，旧自定义配置也适用：显式关闭思考模式以支持指定工具选择，省略 `strict` 和文档未定义的 `parallel_tool_calls`。其他供应商关闭严格模式时也省略 `strict`。所有模式仍执行本机结构、来源和保存校验。当前适配器支持 Chat Completions；OpenCode Zen 中使用其他格式的模型不可直接使用。

手动启动 `NotesService` 后，事务冻结课堂来源版本及全部批次。照片最多六张、正文最多六千字符；大段人工文本按字符上限切成批次输入，保留原段落编号。

关闭「让模型读取照片内容」后，分批快照只包含转写段落，不包含照片编号或图片；原图和选择状态仍保留在本机，渲染与导出时根据转写来源编号和拍照时的录音时间自动插入对应小节。只含照片的课堂在文字模式下不能发起整理。恢复旧图文任务时检查当前配置允许读图，否则要求启用并测试读图或发起新的文字任务，防止恢复任务绕过照片开关。

任务状态为 `waiting/running/completed`。网络、兼容性、来源变化或系统时限错误将任务置为等待手动继续。每个已保存批次由 `jobId + batchId + revision` 唯一约束；同批次不会重复追加。

模型通过 `save_class_notes` 返回完整 JSON 字符串参数。核心模块拒绝未知工具、错误类型、额外字段、空笔记、无来源、跨批次引用、错误照片时间及模型提供的图片路径。实际保存完成后，才创建并回传成功工具回执。数据库持久化原始 assistant 消息及 tool 回执；保存后网络中断的恢复直接复用该消息完成确认。

原始照片留在手机；上传时按最长边缩小并编码 JPEG。模型获得照片编号、原文件名、音频时间和相邻图片。API Key 仅参与 HTTP 鉴权，由 Android Keystore 加密保存；不写入日志、笔记、任务快照或导出。

## 阅读和导出

批次按序合并为 Markdown，来源显示为段落录音时间，图片由本地编号映射插入。模型未引用的照片按录音时间匹配所引用的转写段落并插入对应小节；讲话间隙匹配前一来源，开头/结尾匹配最近可用来源。模型已明确引用的位置保留，每张照片只出现一次。只有没有任何可用文字来源的照片才附在末尾。CommonMark 渲染时转义原始 HTML，WebView 阻止网络加载，KaTeX 及字体在 APK 内供离线公式渲染。

PDF 使用 Android 打印服务默认 A4 白底；Markdown ZIP 保留相对图片路径和原文件名。长表格、跨页图片和复杂公式需要在真机打印预览中验收。
