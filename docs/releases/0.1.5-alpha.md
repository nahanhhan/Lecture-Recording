RecNote 0.1.5-alpha 新增音频导入、可重命名的模型配置预设、OpenCode Go 入口，并修正横屏照片方向。

- 导入 MP3、AAC、WAV、M4A，在本机转换与转写，可回听并整理文字笔记。导入记录不追加麦克风录音或照片；未完成的处理可手动继续。
- 默认提供“预设一”和“预设二”，支持新增及重命名；旧配置与加密密钥保留，预设分别保存配置和测试状态。
- OpenCode Go 使用独立套餐地址，带真实应用身份与稳定会话编号。当前接入其 Chat Completions 模型；官方主要面向编程代理，实际账号能否接受课堂整理请求仍需测试。
- 拍照跟随设备方向，缩略图与发送给模型的图片遵循照片方向信息，保留原图。
- 本安装包经过体积优化，沿用仓库固定签名，可更新此前使用相同仓库签名的版本。

首次使用导入音频需安装本地识别模型。云端仅在手动整理时收到转写文字；供应商账号权限、额度和网络状况需在设置中测试。
