# Spec Delta

## Purpose

定义应用日志的级别控制、隐私脱敏、文件持久化与导出分享行为：用户可按 None / Info / Debug 三档控制记录范围，并将日志导出为 .log 文件经系统分享提供给开发者排查问题。

## ADDED Requirements

### Requirement: 日志级别选择与持久化

设置页最下方 SHALL 提供「日志」区块与 None / Info / Debug 三档级别选择。级别切换 SHALL 立即生效并持久化，应用重启后保持。默认级别 MUST 为 None。

#### Scenario: 首次默认关闭

- **WHEN** 用户从未设置过日志级别并打开设置页
- **THEN** 日志级别处于 None 档，应用不记录任何日志

#### Scenario: 切换级别并重启后保持

- **WHEN** 用户将日志级别切到 Info 后完全退出并重新打开应用
- **THEN** 日志级别仍为 Info 档，后续日志按 Info 规则记录

### Requirement: None 级别关闭日志

当级别为 None 时，系统 MUST NOT 向日志文件写入任何内容；切换到 None 后立即停止后续记录，已记录内容保留至被导出或清理。

#### Scenario: 切到 None 后不再产生新日志

- **WHEN** 用户将级别从 Debug 切到 None 后继续使用应用（录音、下载、整理等）
- **THEN** 日志文件不再新增任何条目

### Requirement: Info 级别记录关键事件并脱敏隐私信息

Info 级别 SHALL 记录关键事件与状态变化，但隐私信息（API Key、密钥材料、Authorization 头等凭据）MUST NOT 写入日志文件。

#### Scenario: 保存云端配置时 API Key 不落盘

- **WHEN** 日志级别为 Info 且用户保存含 API Key 的云端配置
- **THEN** 日志仅记录保存事件与非敏感元数据（如模型名称、结果状态），日志文件中不出现 API Key 的任何部分

#### Scenario: Info 记录录音关键事件

- **WHEN** 级别为 Info 且一次录音从开始到结束
- **THEN** 日志包含录音开始、分段完成、录音结束等关键事件条目

### Requirement: Debug 级别全盘记录

Debug 级别 SHALL 记录全部细节（含请求/响应正文等），以抓问题优先，覆盖 Info 级别条目。

#### Scenario: Debug 记录请求细节

- **WHEN** 级别为 Debug 且云端笔记整理发起一次模型调用
- **THEN** 日志包含该次调用的完整请求与响应内容（可能含隐私信息），足以还原问题现场

### Requirement: 关键流程日志覆盖

核心流程（录音、语音识别、模型下载、云端笔记整理、导出/打印、启动恢复）的关键事件与错误 SHALL 记录日志，每条含时间戳、级别与来源标识；错误 MUST 记录可读原因。

#### Scenario: 模型下载失败可追溯

- **WHEN** 级别非 None 且模型下载因网络中断失败
- **THEN** 日志包含下载开始、进度关键点与失败原因（如 HTTP 状态码或 IO 错误）条目

#### Scenario: 云端整理失败可追溯

- **WHEN** 级别非 None 且云端笔记整理因接口错误失败
- **THEN** 日志记录失败发生阶段与错误信息，可用于定位问题

### Requirement: 多进程日志一致

ASR 独立进程（`:asr`）的日志事件 SHALL 与主进程一同进入可导出的日志内容，级别切换对两个进程均生效，导出条目可区分来源进程。

#### Scenario: ASR 事件随导出可见

- **WHEN** 级别为 Info 或 Debug 且完成一次由 `:asr` 进程执行的语音识别
- **THEN** 导出的 .log 中包含该识别过程的事件条目，且条目标注来源进程

### Requirement: 日志文件持久化与容量上限

日志 SHALL 追加写入应用私有存储的 .log 文件，每行含时间戳、级别与来源；日志文件超过上限（约 5 MB）时 MUST 丢弃最旧内容，MUST NOT 无界增长。

#### Scenario: 超限保留最近内容

- **WHEN** 持续记录使日志文件大小达到上限
- **THEN** 丢弃最旧的日志内容，保留最近内容，文件大小回落到上限以内

### Requirement: 日志占用展示与清理

设置页「日志」区块 SHALL 显示当前日志占用（KB，如「当前日志占用： xxxKB」）并提供「清理日志」按钮；清理后删除全部已记录日志内容，占用显示归零，已清理内容 MUST NOT 再被导出。

#### Scenario: 显示当前日志占用

- **WHEN** 用户打开设置页且日志文件存在已记录内容
- **THEN** 「日志」区块显示「当前日志占用： xxxKB」，数值与日志文件实际占用一致

#### Scenario: 清理日志

- **WHEN** 用户点击「清理日志」
- **THEN** 全部日志内容被删除，占用显示为 0 KB；此后导出提示无日志可导出，除非又产生新日志

### Requirement: 日志导出与系统分享

设置页 SHALL 提供「导出日志」，将当前可导出的日志内容生成单个 .log 文件并通过系统分享面板分享；导出内容仅包含当前级别规则允许记录的内容。

#### Scenario: 导出唤起系统分享

- **WHEN** 用户点击「导出日志」且存在日志内容
- **THEN** 生成 .log 文件并唤起系统分享面板，分享 MIME 类型为纯文本

#### Scenario: 无可导出内容时提示

- **WHEN** 用户点击「导出日志」但没有任何日志内容（如级别为 None 且从未记录过）
- **THEN** 界面提示无日志可导出，不唤起分享面板
