# Spec Delta

## Purpose

定义应用品牌呈现的统一口径：启动器图标图形在各图标变体中的留白与居中规则，以及用户可见软件名称的文案一致性。

## ADDED Requirements

### Requirement: 图标图形四周留白与居中

各启动器图标变体（自适应图标前景、圆形图标、旧式全幅矢量图）中，图形 SHALL 等比缩放且中心红圆圆心与画布中心重合（红圆为图形几何中心），图形可见外框长边 SHALL 恰为图标画布边长的 50%（即完全位于画布中心 50%×50% 区域内）；四边留白 SHALL 各不少于画布边长的 25%。图形七条路径的形状与配色（`#222222`/`#ffffff`/`#d32f2f`）MUST 保持不变；留白区域 MUST 为纯白背景（自适应前景层为透明，由白色背景色呈现）。

#### Scenario: 遮罩下完整可见

- **WHEN** 在圆形、圆角或方圆形启动器遮罩下查看应用图标
- **THEN** 图形完整可见、任一边不被遮罩裁切，且图形边缘与遮罩边缘之间存在明显留白

#### Scenario: 各图标变体几何一致

- **WHEN** 比较自适应图标前景、圆形图标与旧式矢量图标的图形外框
- **THEN** 三者图形外框长边均恰为画布边长的 50%（允许 ±1 视口单位误差），且中心红圆圆心均与画布中心重合

#### Scenario: 预览图与实际图标一致

- **WHEN** 查看 README 中的图标预览图
- **THEN** 预览图中图形外框长边占画布 50%、四周留白比例与实际启动器图标一致

### Requirement: 用户可见软件名称统一为「RecNote」

启动器应用标签、主界面顶栏标题与录音服务通知标题 SHALL 均显示「RecNote」；运行时用户可见文案 MUST NOT 出现「课堂录音笔」。页面级标题（设置页「设置」、详情页「课堂记录」）MUST 保持不变。

#### Scenario: 启动器显示新名称

- **WHEN** 安装应用后在系统启动器中查看应用名称
- **THEN** 名称显示「RecNote」

#### Scenario: 主界面顶栏显示新名称

- **WHEN** 用户打开应用主界面（首页）
- **THEN** 顶栏标题显示「RecNote」；进入设置页与详情页时标题分别仍为「设置」与「课堂记录」

#### Scenario: 录音通知显示新名称

- **WHEN** 录音服务运行并发出常驻通知
- **THEN** 通知标题显示「RecNote」
