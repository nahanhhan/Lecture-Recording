# 0.1.5-alpha 验证

2026-10-03。基于 GitHub 最新 `c247e70eba1ab38d9c8b004d0c5841dbb6a2aa68`；开发及调试前多次核对远端，无其他成员新提交。

## 实现

- 项目规则写入根目录 AGENTS.md：GitHub 为准，开发/调试前检查，上载前复查，禁止强制覆盖；每个版本提供 Release APK。
- OpenCode Go 独立接口、真实应用身份、稳定任务会话编号。支持 Go / Go Plus 密钥及其 Chat Completions 模型；套餐是否接受课堂整理请求需实际账号验证。
- 可新增、重命名及切换配置预设；默认预设一/二，保留旧配置及加密密钥，各自保存配置和测试状态。
- MP3、AAC、WAV、M4A 导入：本机流式解码、合并声道与重采样、回听 WAV、分段转写与文字笔记，暂停/继续；不要求麦克风权限、不追加录音或照片。
- 拍摄方向随设备更新，图片显示与上传遵循 EXIF，原图不改写；横屏重建时保持拍照界面，修正首次加载误判记录删除的问题。
- 新增 compact 构建：体积优化且沿用仓库固定签名。版本标签触发测试、构建和 GitHub Release APK 发布；拒绝修改已有不同内容的资源或不同提交的版本标签。

## 已验证

- 核心 JVM 测试 49 项通过：包括重采样长度、低通抑制混叠、旋转角度边界、Go 地址、来源验证及原有存储测试。
- HTTP 单元测试 6 项通过：HTTPS、错误信息、脱敏、取消、Go 路径与身份/会话头。
- Android API 34 x86_64 隔离应用 18 项通过，含定向重测：四格式真实解码、导入保存、跳过已保存转写、失败不提交部分数据、预设/UI、旧数据迁移、EXIF/云端图像、无麦克风权限的导入服务、拍照界面重建、原有删除和解压回归。
- 发布脚本 6 项测试通过：精确提交、已有资源保留、不替换不同 APK、不发布到不同标签提交、上传大小/摘要检查、凭据域名限制。
- 项目静态检查 5 项通过。
- Debug 与 Compact 单元测试各 6 项通过，静态检查均为 0 个错误（47 个建议级警告）；两种 arm64 安装包成功构建。
- 另以独立 `.compacttest` 应用安装优化过的 x86_64 APK，验证首页启动、加密设置初始化和预设切换，并检查实际页面截图。

四格式测试素材为自行生成的 3 秒 440 Hz 音频，无用户录音；完整导入流程测试的识别回调为测试实现，平台解码是真实执行。模型识别质量和目标手机长时性能仍需实际录音验收；未使用真实云端模型密钥发起请求。
