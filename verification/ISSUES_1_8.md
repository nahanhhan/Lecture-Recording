# 模型安装与录音删除验证

日期：2026-10-03。版本：0.1.3-alpha，versionCode 3。

基于云端最新提交 `188922d1a216ea70f0ed41b2de6c6994750b524f` 实现，保留已有图标、RecNote 名称、下载源、日志功能和固定调试签名。

## 模型安装（issue #1）

[原 issue 日志](https://github.com/nahanhhan/RecNote/issues/1#issuecomment-5963638693) 显示，模型归档校验不到一秒，随后解压安装约 45 分钟。本次改用官方 libbzip2 1.0.8 的原生实现，并在解压写入时计算每个模型文件的 SHA-256，减少重复读取；校验、安装分别显示进度，处理期间使用有超时及续租的唤醒锁。

解压仍只输出允许的模型文件，检查文件大小、重复条目、缺失文件和剩余空间。归档 SHA-256 校验保留，截断或损坏的 bzip2 数据会报错。取消操作按有限大小的数据块检查。

测试环境：专用 Android 14 / API 34 x86_64 模拟器，测试应用 ID 带 `.uitest` 后缀，与正常安装及其数据隔离。

| 测试 | 结果 |
| --- | --- |
| 同一份 2 MiB 随机数据，旧 Java 解压 | 4,661 ms |
| 同一份数据，原生解压 | 100 ms，逐字节结果一致 |
| 完整默认 AED 官方归档 | 输入 838,589,068 字节；归档 SHA-256 与固定值一致 |
| 完整 AED 解压、写入及逐文件哈希 | 55,137 ms；输出 1,234,657,933 字节；4,743 次进度回调 |
| 截断归档 | 正确抛出错误 |

样本约加速 46.6 倍；完整模型数据为本次模拟器测量。原 issue 来自另一设备，不能将这两组耗时当作同一手机上的前后比较。目标手机的锁屏安装耗时仍需复测。

原生源码及原始包校验值位于 `app/src/main/cpp/bzip2/`，许可证位于 `third_party/bzip2-LICENSE`。

## 删除录音（issue #8）

- 点击录音进入详情，可选择「删除录音」。
- 列表长按录音或点击「多选」，支持逐条选择、全选、取消全选和批量删除。
- 删除前确认，音频、照片、转写、笔记、整理批次及该记录的本地 Markdown ZIP 缓存一并清理。
- 正在录音、转写或整理的记录不可删除；删除与后台任务开始通过同一把操作锁协调，避免记录被重新创建。
- 删除先将文件移入应用内部临时目录，再事务删除关联数据。失败或启动恢复时，根据数据库现状恢复文件或完成清理，防止半途出错丢失其他记录。

核心测试与模拟器集成测试已验证：取消删除保留资料、详情删除后返回列表、长按多选及全选、批量删除、关联数据和文件清理、处理中记录保护，以及其他录音和共享模型不受影响。

## 重现测试

先准备 sherpa x86_64 运行库，再构建隔离测试应用：

```sh
python scripts/bootstrap.py --native --abi x86_64
./gradlew :core:test :app:connectedDebugAndroidTest -PtestAbi=x86_64 -PisolatedTest=true
```

完整模型基准为可选测试，需要先把已校验的官方 AED 归档放入隔离应用可读目录，再单独运行 `ModelInstallBenchmarkTest` 并传入 `benchmark_archive` 路径。普通测试不下载大模型，不操作正常应用的数据。
